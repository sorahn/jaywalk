# Documentation

- [Settings reference](settings.md): configuration keys, defaults, allowed
  values and live-reload/persistence behavior.
- [Keybindings](keybindings.md): shortcut defaults, every application command,
  widget remapping, navigation behavior and conventions from other diff apps.

See the [project README](../README.md) for building, launching, repository
integration and viewer workflows. The [default settings](../config/default.toml) and
[default keybindings](../config/keybindings.toml)
are the canonical defaults. The sparse [user settings](../config/user.toml) and
[user keybindings](../config/user-keybindings.toml) templates are generated on first use.
